Python workshop, week 4: sets, nested data, text

Sets

In these notes, the block right after a piece of code shows what that code prints, or the last line of the error it raises.

A set holds each value at most once and has no order. Use one to remove duplicates and to ask quickly whether a value has been seen.

walkers = ["ana", "ben", "ana", "cy", "ben"]
unique = set(walkers)
print(len(walkers), len(unique))
print("ana" in unique, "dee" in unique)
unique.add("dee")
unique.add("ana")
print(sorted(unique))
5 3
True False
['ana', 'ben', 'cy', 'dee']

Adding a value that is already there changes nothing. A set prints in no particular order, so sort it before showing it. To keep the first of each value in its original order, use a set next to a list:

seen = set()
first_visits = []
for walker in walkers:
    if walker not in seen:
        seen.add(walker)
        first_visits.append(walker)
print(first_visits)
['ana', 'ben', 'cy']

Set operations

Two sets combine as in mathematics: | is the union (in either), & the intersection (in both), - the difference (in the first but not the second). <= tests whether every item of the first is in the second.

saturday = {"ana", "ben", "cy"}
sunday = {"ben", "cy", "dee"}
print(sorted(saturday | sunday))
print(sorted(saturday & sunday))
print(sorted(saturday - sunday))
print(saturday <= {"ana", "ben", "cy", "dee"})
['ana', 'ben', 'cy', 'dee']
['ben', 'cy']
['ana']
True

Each operation returns a new set and leaves both operands as they were. The difference is not symmetric: sunday - saturday is the set with dee only.

Lists of dictionaries

Records with named fields are often kept as a list of dictionaries, the shape that data read from a file usually has. Reach a value step by step: the list's position, then the key, then inside that value.

trails = [
    {"name": "Loop", "km": 12.5, "tags": ["forest", "river"]},
    {"name": "Falls", "km": 7.0, "tags": ["river"]},
    {"name": "Ridge", "km": 5.5, "tags": []},
]
print(trails[1]["name"])
print(trails[0]["tags"][-1])
for trail in trails:
    print(trail["name"], len(trail["tags"]))
Falls
river
Loop 2
Falls 1
Ridge 0

A comprehension picks one field from the records that pass a test:

long_ones = [trail["name"] for trail in trails if trail["km"] > 6]
print(long_ones)
['Loop', 'Falls']

Nested summaries

Grouping by two things gives a dictionary whose values are dictionaries. setdefault gives the inner dictionary, creating it the first time a walker is seen; the inner one is then counted into as usual.

log = [("ana", "Loop", 12), ("ben", "Falls", 7), ("ana", "Falls", 7), ("ana", "Loop", 12)]
summary = {}
for walker, trail, km in log:
    per_trail = summary.setdefault(walker, {})
    per_trail[trail] = per_trail.get(trail, 0) + km
print(summary)
print(summary["ana"]["Loop"])
{'ana': {'Loop': 24, 'Falls': 7}, 'ben': {'Falls': 7}}
24

A record that belongs to several groups is added to each of them. A trail without tags appears in no group:

by_tag = {}
for trail in trails:
    for tag in trail["tags"]:
        by_tag.setdefault(tag, []).append(trail["name"])
print(by_tag)
{'forest': ['Loop'], 'river': ['Loop', 'Falls']}

Processing text

Counting words needs the text made uniform first: one case, and no punctuation stuck to a word. strip with an argument removes those characters from both ends of a string, not from its middle.

note = "Steep, but short. Steep climbs are short climbs!"
words = []
for raw in note.lower().split():
    word = raw.strip(".,!?")
    if word:
        words.append(word)
print(words)
['steep', 'but', 'short', 'steep', 'climbs', 'are', 'short', 'climbs']
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
top = sorted(counts.items(), key=lambda pair: (-pair[1], pair[0]))
print(top[:3])
[('climbs', 2), ('short', 2), ('steep', 2)]

Three words tie at 2, so the second part of the key, the word itself, decides their order. Other string methods that return a new string or an answer:

print("Blue Ridge".replace("Blue", "Red"))
print("Blue Ridge".startswith("Blue"), "Blue Ridge".find("Ridge"), "Blue Ridge".find("Loop"))
Red Ridge
True 5 -1

Formatting output

Inside an f-string, a format follows the value after a colon: a width, an alignment (< left, > right), a number of decimals. Exercises that print a report are checked character by character, so the format matters.

for name, km in [("Loop", 12.5), ("Falls", 7.0)]:
    print(f"{name:<6}|{km:>6.1f}|")
print(f"{1234567:,}")
print(f"{0.256:.1%}")
print(f"{7:03d}")
print(round(2.675, 1), f"{2.675:.1f}", round(7.0))
Loop  |  12.5|
Falls |   7.0|
1,234,567
25.6%
007
2.7 2.7 7
  • :<6 pads on the right to 6 characters; :>6.1f is one decimal, padded on the left to 6.
  • :, adds thousands separators, :.1% multiplies by 100 and adds the sign, :03d pads a whole number with zeros.
  • round(x, 1) gives a number; a format gives text. Round only when showing a result, never in the middle of a calculation.

Asking questions of a collection

max and min take a key as sorted does, and return the item itself, not the key. sum, any and all take a generator expression: a comprehension without brackets that builds no list.

print(max(trails, key=lambda trail: trail["km"])["name"])
print(min(trails, key=lambda trail: len(trail["tags"]))["name"])
print(sum(trail["km"] for trail in trails))
print(any(trail["km"] > 12 for trail in trails))
print(all(trail["tags"] for trail in trails))
print(max([], default=0))
Loop
Ridge
25.0
True
False
0
  • any is true when at least one item is true, all when none is false. Ridge has an empty list of tags, which counts as false.
  • max and min of an empty collection are an error unless default is given; sum of nothing is 0.
  • When several items share the largest key, max returns the first of them.

Common mistakes

Empty braces are a dictionary. The empty set is written set().

print(type({}), type(set()), type({1}))
<class 'dict'> <class 'set'> <class 'set'>

A set has no positions.

unique[0]
TypeError: 'set' object is not subscriptable

Rows that are the same list. * repeats a reference to one inner list, so changing one row changes all of them. Build each row in a comprehension:

grid = [[0] * 3] * 2
grid[0][0] = 9
print(grid)
fixed = [[0] * 3 for _ in range(2)]
fixed[0][0] = 9
print(fixed)
[[9, 0, 0], [9, 0, 0]]
[[9, 0, 0], [0, 0, 0]]

Removing from a dictionary while looping over it.

totals = {"ana": 31, "ben": 7, "cy": 12}
for walker in totals:
    if totals[walker] < 10:
        del totals[walker]
RuntimeError: dictionary changed size during iteration

Build a new dictionary of what to keep:

totals = {"ana": 31, "ben": 7, "cy": 12}
totals = {walker: km for walker, km in totals.items() if km >= 10}
print(totals)
{'ana': 31, 'cy': 12}
