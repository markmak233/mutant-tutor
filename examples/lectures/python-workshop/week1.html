Python workshop, week 1: values, strings, lists, loops

Values and types

In these notes, the block right after a piece of code shows what that code prints, or the last line of the error it raises.

Every value in Python has a type, and the type decides what an operator does. The four types of this week are int (whole numbers), float (numbers with a fractional part), str (text) and bool (True or False).

print(7 + 2)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(type(7), type(7.0), type("7"), type(True))
9
3.5
3
1
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>
  • / always gives a float, even when the division is exact.
  • // is floor division: it drops the fractional part.
  • % is the remainder; n % 2 == 0 tests whether n is even.

Text that looks like a number is still text. Convert it before doing arithmetic:

print(int("12") + 1)
print(str(12) + "1")
print(float("2.5") * 2)
13
121
5.0

+ adds two numbers and joins two strings; it refuses one of each.

Names and assignment

An assignment makes a name refer to a value. The right-hand side is evaluated first, then the name is bound to the result, so a name may appear on both sides.

distance = 12.5
climb = 640
distance = distance + 3
climb += 60
print(distance, climb)
15.5 700

climb += 60 is short for climb = climb + 60. A single = assigns; a double == compares.

Strings

A string is a sequence of characters. Positions start at 0, and a negative position counts from the end. A slice text[start:stop] takes the characters from start up to, but not including, stop.

name = "  Blue Ridge Loop \n"
clean = name.strip()
print(clean)
print(clean.lower())
print(len(clean))
print(clean[0], clean[-1])
print(clean[5:10])
Blue Ridge Loop
blue ridge loop
15
B p
Ridge

strip() removes spaces and line ends from both ends. split() cuts a string into a list of words, join() puts a list of strings back together, and an f-string places values inside text.

words = clean.split()
print(words)
print("-".join(words))
print(f"{clean}: {len(words)} words")
['Blue', 'Ridge', 'Loop']
Blue-Ridge-Loop
Blue Ridge Loop: 3 words

Strings are immutable: no method changes a string in place. strip() and lower() return a new string, which is why the result was stored in clean. Assigning to one character is an error:

clean[0] = "b"
TypeError: 'str' object does not support item assignment

Lists

A list holds values in order. It is indexed and sliced like a string, but it is mutable: append adds an item at the end, and an item can be replaced by assignment.

climbs = [640, 120, 880]
climbs.append(300)
print(climbs)
print(len(climbs), climbs[0], climbs[-1])
print(climbs[1:3])
climbs[1] = 150
print(climbs)
[640, 120, 880, 300]
4 640 300
[120, 880]
[640, 150, 880, 300]

Assigning a list to a second name does not copy it: both names refer to the same list. A full slice climbs[:] makes a new list with the same items.

same = climbs
copy = climbs[:]
same.append(50)
print(climbs)
print(copy)
[640, 150, 880, 300, 50]
[640, 150, 880, 300]

The last valid position of a list of 5 items is 4. Reading past it is an error:

print(climbs[5])
IndexError: list index out of range

for loops

A for loop runs its indented body once for each item of a sequence. The loop variable takes each item in turn.

for climb in [640, 150, 880]:
    print(climb * 2)
1280
300
1760

range(n) gives the numbers 0 to n - 1. range(start, stop, step) starts at start and stops before stop.

for i in range(3):
    print(i)
print(list(range(2, 10, 3)))
0
1
2
[2, 5, 8]

When the position is needed as well as the item, enumerate gives both. Loop over the items themselves whenever the position is not needed.

trails = ["Loop", "Ridge", "Falls"]
for number, trail in enumerate(trails, start=1):
    print(number, trail)
1 Loop
2 Ridge
3 Falls

Conditions

if, elif and else choose one branch. The conditions are tested from the top, and only the first true one runs, so their order matters.

climb = 880
if climb >= 800:
    grade = "hard"
elif climb >= 300:
    grade = "moderate"
else:
    grade = "easy"
print(grade)
hard

Comparisons can be chained, and and, or, not combine them. Any value can be used as a condition: zero, an empty string and an empty list count as false, everything else as true.

print(300 <= climb < 800)
print(climb > 800 and grade == "hard")
print(not trails)
print(bool(""), bool("0"), bool(0), bool([0]))
False
True
False
False True False True

"0" is a string with one character and [0] is a list with one item, so both are true.

Accumulating a result

Most loops build one result from many items. The pattern is always the same: give the result a starting value before the loop, update it inside the loop, use it after the loop.

climbs = [640, 150, 880, 300]
total = 0
hard = 0
highest = climbs[0]
for climb in climbs:
    total += climb
    if climb >= 800:
        hard += 1
    if climb > highest:
        highest = climb
print(total, hard, highest)
print(total / len(climbs))
1970 1 880
492.5
  • A sum and a count start at 0.
  • A maximum starts at the first item, not at 0: with only negative values, 0 would be wrong.
  • An average divides by the number of items, so an empty list must be handled before it.

A while loop repeats as long as its condition is true. Use it when the number of repetitions is not known in advance.

remaining = 1000
days = 0
while remaining > 0:
    remaining -= 300
    days += 1
print(days, remaining)
4 -200

Common mistakes

Converting text that is not a whole number. int accepts only digits (and a sign); convert with float first when a fractional part is possible.

int("3.5")
ValueError: invalid literal for int() with base 10: '3.5'

Off by one. range(1, 5) stops before 5, as a slice does.

print(list(range(1, 5)))
[1, 2, 3, 4]

Changing a list while looping over it. Removing an item moves the later ones one place forward, and the loop then skips the item that took the removed one's place. Here the second 2 survives:

values = [1, 2, 2, 3]
for value in values:
    if value == 2:
        values.remove(value)
print(values)
[1, 2, 3]

Build a new list of the items to keep instead:

values = [1, 2, 2, 3]
kept = []
for value in values:
    if value != 2:
        kept.append(value)
print(kept)
[1, 3]
