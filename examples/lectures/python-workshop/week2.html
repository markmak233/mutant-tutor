Python workshop, week 2: dictionaries, functions, sorting

Tuples and unpacking

In these notes, the block right after a piece of code shows what that code prints, or the last line of the error it raises.

A tuple is a fixed group of values, written with commas and usually parentheses. It is the natural shape for one record: a trail's name, its length in km and its climb in metres. Unpacking gives each part a name in one assignment.

trip = ("Loop", 12.5, 640)
name, distance, climb = trip
print(name, climb)
print(trip[1])
Loop 640
12.5

Unpacking also works in a loop over a list of tuples, which reads better than indexing:

pairs = [("Loop", 640), ("Falls", 300)]
for name, climb in pairs:
    print(f"{name} climbs {climb} m")
Loop climbs 640 m
Falls climbs 300 m

A tuple is immutable, like a string:

trip[2] = 700
TypeError: 'tuple' object does not support item assignment

Dictionaries

A dictionary maps keys to values. Looking a key up does not depend on how many keys there are, which is why a dictionary, not a list, is used to find something by name.

climbs = {"Loop": 640, "Falls": 300}
climbs["Ridge"] = 880
print(climbs["Loop"])
print(len(climbs))
print("Falls" in climbs, 300 in climbs)
print(climbs.get("Summit"))
print(climbs.get("Summit", 0))
640
3
True False
None
0
  • in tests the keys, never the values.
  • get(key) gives None for a missing key, and get(key, default) gives the default.
  • Square brackets with a missing key are an error:
climbs["Summit"]
KeyError: 'Summit'

Counting and grouping

Two patterns cover most uses of a dictionary. Counting: the value is a number that grows each time the key is seen. get(key, 0) supplies the 0 the first time.

walkers = ["ana", "ben", "ana", "cy", "ana", "ben"]
counts = {}
for walker in walkers:
    counts[walker] = counts.get(walker, 0) + 1
print(counts)
{'ana': 3, 'ben': 2, 'cy': 1}

Grouping: the value is a list that collects every item with that key. setdefault(key, []) gives the key's list, creating an empty one the first time.

log = [("ana", 12), ("ben", 7), ("ana", 5), ("ben", 9)]
by_walker = {}
for walker, km in log:
    by_walker.setdefault(walker, []).append(km)
print(by_walker)
{'ana': [12, 5], 'ben': [7, 9]}

A dictionary keeps its keys in the order they were first inserted.

Looping over a dictionary

items() gives each key with its value, as pairs to unpack. Looping over the dictionary itself gives the keys only, and values() the values only.

for walker, kms in by_walker.items():
    print(walker, sum(kms), max(kms))
ana 17 12
ben 16 9
print(list(counts))
print(sorted(counts.values()))
['ana', 'ben', 'cy']
[1, 2, 3]

sum, max, min and len take a whole list, so a summary of one group needs no loop of its own.

Functions

A function names a piece of work. Its parameters receive the caller's values, and return hands a result back to the caller.

def average(values):
    return sum(values) / len(values)

print(average([12, 5]))
8.5

Returning is not printing. A function that only prints gives its caller None, so its result cannot be stored, compared or tested:

def show_average(values):
    print(sum(values) / len(values))

result = show_average([12, 5])
print(result)
8.5
None

return also ends the function at once, so a chain of tests needs no else:

def grade(climb):
    if climb >= 800:
        return "hard"
    if climb >= 300:
        return "moderate"
    return "easy"

print(grade(880), grade(300), grade(299))
hard moderate easy

Default and keyword arguments

A parameter with a default may be left out by the caller. Arguments can also be given by name, in any order.

def pace(km, hours, digits=1):
    return round(km / hours, digits)

print(pace(12.5, 3))
print(pace(12.5, 3, 3))
print(pace(hours=3, km=12.5, digits=0))
4.2
4.167
4.0

A default is created once, when the function is defined, not at each call. A list used as a default is therefore shared by every call that leaves the argument out:

def add_trip(name, trips=[]):
    trips.append(name)
    return trips

print(add_trip("Loop"))
print(add_trip("Falls"))
['Loop']
['Loop', 'Falls']

Use None as the default and make the list inside the function:

def add_trip(name, trips=None):
    if trips is None:
        trips = []
    trips.append(name)
    return trips

print(add_trip("Loop"))
print(add_trip("Falls"))
['Loop']
['Falls']

Comprehensions

A comprehension builds a list (or a dictionary) from a loop written in one expression: the value to keep, then the loop, then an optional condition.

kms = [12, 7, 5, 9]
print([km * 1000 for km in kms])
print([km for km in kms if km >= 7])
print({walker: sum(group) for walker, group in by_walker.items()})
[12000, 7000, 5000, 9000]
[12, 7, 9]
{'ana': 17, 'ben': 16}

The second line is the same as starting with an empty list and appending inside an if inside a for. Use a comprehension when the body is one expression; keep the ordinary loop when it needs several steps.

Sorting

sorted returns a new list in increasing order and leaves its argument alone. key names what to compare, and reverse=True gives decreasing order.

totals = {"cy": 17, "ben": 16, "ana": 17}
print(sorted(totals))
print(sorted(totals.items(), key=lambda pair: pair[1], reverse=True))
print(sorted(totals.items(), key=lambda pair: (-pair[1], pair[0])))
['ana', 'ben', 'cy']
[('cy', 17), ('ana', 17), ('ben', 16)]
[('ana', 17), ('cy', 17), ('ben', 16)]
  • Sorting is stable: items whose keys are equal stay in their original order. In the second line cy and ana tie at 17, so they stay as the dictionary had them.
  • To decide ties, sort by a tuple. (-pair[1], pair[0]) means: largest total first, and among equal totals the name in alphabetical order.

A list's own sort() method sorts in place and returns None; storing its result is a common mistake.

kms = [12, 7, 5, 9]
ordered = sorted(kms)
print(ordered, kms)
kms.sort()
print(kms)
print(kms.sort())
[5, 7, 9, 12] [12, 7, 5, 9]
[5, 7, 9, 12]
None
