C workshop, week 1: programs, types, loops, functions

A first program

In these notes, each complete program is followed by what it prints. When a program reads input, the input is shown first. A piece of code without main is a fragment: it shows one point and is not a whole program.

A C program is text in a .c file. A compiler turns it into a program the machine can run. Running it starts at the function main.

#include <stdio.h>

int main(void) {
    printf("Hello, trail!\n");
    return 0;
}
Hello, trail!
  • #include <stdio.h> tells the compiler about printf and the other input and output functions.
  • Every statement ends with ;, and { } group the statements of a function.
  • printf adds no line break of its own: \n is the line break.
  • return 0; in main is the program's exit status. 0 means success; any other value tells whoever ran the program that it failed.

Compile and run it in a terminal:

gcc -Wall -std=c11 -o hello hello.c
./hello

-Wall turns on the usual warnings and -std=c11 chooses the version of the language. Treat every warning as a mistake to fix: in C a warning is very often a real bug.

Variables and types

A variable has a type, fixed when it is declared. The three types of this week are int (whole numbers), double (numbers with a fractional part) and char (one character). printf needs a format that matches each value's type.

#include <stdio.h>

int main(void) {
    int climb = 640;
    double distance = 12.5;
    char grade = 'B';
    printf("%d m\n", climb);
    printf("%f km\n", distance);
    printf("%.1f km, grade %c\n", distance, grade);
    return 0;
}
640 m
12.500000 km
12.5 km, grade B
  • %d prints an int, %f a double with six decimals, %.1f a double with one decimal, %c a char.
  • A character is written in single quotes ('B'), a string in double quotes ("B"). They are different types.
  • A variable declared without a value does not start at 0: it holds whatever was in memory. Give every variable a value before reading it.

Arithmetic

The type of the operands decides what an operator does. Dividing two int values gives an int: the fractional part is dropped.

#include <stdio.h>

int main(void) {
    int total = 7;
    int count = 2;
    printf("%d\n", total / count);
    printf("%d\n", total % count);
    printf("%.2f\n", (double)total / count);
    printf("%.2f\n", (double)(total / count));
    printf("%c %d\n", 'a' + 1, 'a' + 1);
    return 0;
}
3
1
3.50
3.00
b 98
  • % is the remainder of an integer division.
  • (double)total is a cast: it converts the value before the division, so the division is done on double values.
  • Casting the result is too late: (double)(total / count) divides the integers first and converts 3.
  • A char is a small integer, the character's code, so arithmetic works on it.

Conditions

if, else if and else choose one branch. The conditions are tested from the top and only the first true one runs.

#include <stdio.h>

int main(void) {
    int climb = 880;
    if (climb >= 800) {
        printf("hard\n");
    } else if (climb >= 300) {
        printf("moderate\n");
    } else {
        printf("easy\n");
    }
    printf("%d %d\n", climb > 800 && climb < 900, climb < 300 || climb == 880);
    printf("%d\n", !climb);
    return 0;
}
hard
1 1
0

A comparison gives the int 1 when true and 0 when false, and any value can be a condition: 0 is false, everything else is true. && is and, || is or, ! is not.

= assigns and == compares. This fragment compiles, and its branch always runs:

if (climb = 300) {      /* assigns 300 to climb, then tests 300: true */
    printf("moderate\n");
}

-Wall warns about it. Always write the braces, even around one statement: without them only the first statement belongs to the if.

Loops

for is the loop for counting: a start, a condition tested before each round, and a step done after each round. while repeats as long as its condition is true. break leaves the loop; continue goes straight to the next round.

#include <stdio.h>

int main(void) {
    int sum = 0;
    for (int i = 1; i <= 5; i++) {
        sum += i;
    }
    printf("%d\n", sum);

    int remaining = 1000;
    int days = 0;
    while (remaining > 0) {
        remaining -= 300;
        days++;
    }
    printf("%d %d\n", days, remaining);

    for (int i = 0; i < 10; i++) {
        if (i % 2 == 0) {
            continue;
        }
        if (i > 6) {
            break;
        }
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
15
4 -200
1 3 5
  • A result built by a loop gets its starting value before the loop: a sum and a count start at 0.
  • i++ adds 1 to i, and sum += i adds i to sum.
  • To go over n items numbered from 0, write for (int i = 0; i < n; i++): with <= the loop runs once too often.

Functions

A function has a return type, a name and typed parameters. The compiler reads the file from the top, so a function used before its definition needs a declaration (a prototype) first: its first line followed by ;.

#include <stdio.h>

double pace(double km, double hours);
void show(int climb);

int main(void) {
    printf("%.2f\n", pace(12.5, 3));
    show(880);
    show(120);
    return 0;
}

double pace(double km, double hours) {
    return km / hours;
}

void show(int climb) {
    if (climb >= 800) {
        printf("%d: hard\n", climb);
        return;
    }
    printf("%d: not hard\n", climb);
}
4.17
880: hard
120: not hard

A void function returns nothing. Arguments are passed by value: the function gets a copy, and changing the copy does not change the caller's variable.

#include <stdio.h>

void add_break(int minutes) {
    minutes += 15;
    printf("inside: %d\n", minutes);
}

int main(void) {
    int minutes = 90;
    add_break(minutes);
    printf("after: %d\n", minutes);
    return 0;
}
inside: 105
after: 90

To give a result back, return it.

Reading input

scanf reads values from standard input. "%d" reads one whole number, skipping spaces and line breaks before it, and stores it where &km points: the & gives scanf the variable's address, so it can fill the variable in (week 2 explains addresses). scanf returns how many values it stored, so the loop below ends when the input does, or at the first thing that is not a number.

#include <stdio.h>

int main(void) {
    int km;
    int total = 0;
    int count = 0;
    while (scanf("%d", &km) == 1) {
        total += km;
        count++;
    }
    if (count == 0) {
        printf("no trips\n");
        return 0;
    }
    printf("%d trips, %d km, average %.1f\n", count, total, (double)total / count);
    return 0;
}
12 7
6
3 trips, 25 km, average 8.3
  • Always test what scanf returns. When it stores nothing, the variable keeps its old value, or no value at all.
  • The empty input is handled before the division: dividing by a count of 0 is an error.

Common mistakes

Integer division where a fraction was meant. Both operands are int, so the division gives 0 before the result is stored in a double:

#include <stdio.h>

int main(void) {
    double share = 1 / 4;
    double fixed = 1.0 / 4;
    printf("%.2f %.2f\n", share, fixed);
    return 0;
}
0.00 0.25

**A missing & in scanf.** scanf then takes the variable's value for an address and writes somewhere it must not:

scanf("%d", km);        /* wrong: must be &km */

One round too many. An array of n items has positions 0 to n - 1:

for (int i = 0; i <= n; i++) {      /* wrong: must be i < n */
    total += values[i];
}

Missing braces. The indentation means nothing to the compiler; the second line below runs whatever climb is:

if (climb >= 800)
    printf("hard\n");
    printf("take water\n");

A function that does not return on every path. A function declared to return a value must reach a return whatever its arguments are; -Wall warns when one path has none.
