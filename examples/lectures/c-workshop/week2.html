C workshop, week 2: arrays, strings, pointers

Arrays

In these notes, each complete program is followed by what it prints. When a program reads input, the input is shown first. A piece of code without main is a fragment: it shows one point and is not a whole program.

An array holds a fixed number of values of one type, side by side in memory. Positions start at 0.

#include <stdio.h>

int main(void) {
    int climbs[4] = {640, 150, 880, 300};
    int n = sizeof(climbs) / sizeof(climbs[0]);
    int total = 0;
    int highest = climbs[0];
    for (int i = 0; i < n; i++) {
        total += climbs[i];
        if (climbs[i] > highest) {
            highest = climbs[i];
        }
    }
    printf("%d items, total %d, highest %d\n", n, total, highest);
    climbs[1] = 200;
    printf("%d\n", climbs[1]);
    return 0;
}
4 items, total 1970, highest 880
200
  • The size is part of the declaration and never changes.
  • The valid positions of climbs are 0 to 3. C does not check a position: climbs[4] reads or writes memory that belongs to something else. That is undefined behaviour: the program may crash, print nonsense, or seem to work.
  • sizeof(climbs) / sizeof(climbs[0]) is the number of items: the array's size in bytes divided by one item's. It works only where the array is declared.
  • A maximum starts at the first item, not at 0: with only negative values 0 would be wrong.

Arrays and functions

A function that takes an array receives where the array starts, not a copy of it, and nothing about its length. So the length is passed as well, and a change the function makes is a change to the caller's array.

#include <stdio.h>

int sum(const int values[], int n) {
    int total = 0;
    for (int i = 0; i < n; i++) {
        total += values[i];
    }
    return total;
}

void double_all(int values[], int n) {
    for (int i = 0; i < n; i++) {
        values[i] *= 2;
    }
}

int main(void) {
    int kms[3] = {12, 7, 5};
    printf("%d\n", sum(kms, 3));
    double_all(kms, 3);
    printf("%d %d %d\n", kms[0], kms[1], kms[2]);
    printf("%d\n", sum(kms, 0));
    return 0;
}
24
24 14 10
0
  • const in sum is a promise not to change the items; the compiler refuses an assignment to values[i] there.
  • Inside a function, sizeof(values) is the size of an address, not of the array: the number of items cannot be worked out, only passed.
  • With n equal to 0 the loop does not run and the sum is 0: a function should give a sensible answer for an empty array.

Strings

C has no string type. A string is an array of char that ends with the character '\0', whose code is 0. Every string function finds the end by looking for it.

#include <stdio.h>

int main(void) {
    char name[] = "Ridge";
    int length = 0;
    while (name[length] != '\0') {
        length++;
    }
    printf("%s has %d letters\n", name, length);
    printf("%d bytes\n", (int)sizeof(name));
    name[0] = 'r';
    printf("%s\n", name);
    return 0;
}
Ridge has 5 letters
6 bytes
ridge
  • "Ridge" takes 6 bytes: five letters and the '\0'. An array for a string of n letters needs n + 1 items.
  • %s prints characters up to the '\0'. Without one, it goes on past the end of the array.
  • The characters of an array can be changed one by one, as any array's items.

String functions

string.h declares the usual operations. None of them makes room: the destination array must already be large enough.

#include <stdio.h>
#include <string.h>

int main(void) {
    char trail[16];
    strcpy(trail, "Falls");
    printf("%d\n", (int)strlen(trail));
    printf("%d %d\n", strcmp(trail, "Falls") == 0, strcmp(trail, "Loop") < 0);
    char label[32];
    snprintf(label, sizeof(label), "%s: %d m", trail, 300);
    printf("%s\n", label);
    return 0;
}
5
1 1
Falls: 300 m
  • strlen counts the characters before the '\0'.
  • strcmp returns 0 when two strings are equal, a negative number when the first comes earlier in dictionary order, a positive one when it comes later. Two strings are never compared with ==: that compares where they are stored.
  • strcpy copies a string with its '\0' and does not check the room. Copying a string longer than the destination writes past its end.
  • snprintf works like printf into an array and never writes more than the size it is given.

Pointers

Every variable is stored at an address. A pointer is a variable that holds an address. &x is the address of x; *p is the variable that p points to.

#include <stdio.h>

int main(void) {
    int climb = 640;
    int *p = &climb;
    printf("%d\n", *p);
    *p = 700;
    printf("%d\n", climb);
    int other = 120;
    p = &other;
    *p += 1;
    printf("%d %d\n", climb, other);
    return 0;
}
640
700
700 121
  • int *p declares a pointer to an int.
  • Assigning to *p changes the variable pointed to; assigning to p makes it point to another variable.
  • NULL is the pointer that points to nothing. Using *p when p is NULL, or when p was never given a value, is undefined behaviour, usually a crash.

Pointers as parameters

Arguments are copies, so a function cannot change a caller's variable through its value. Given the variable's address, it can. This is also how a function gives back more than one result.

#include <stdio.h>

void swap(int *a, int *b) {
    int old = *a;
    *a = *b;
    *b = old;
}

void lowest_highest(const int values[], int n, int *lowest, int *highest) {
    *lowest = values[0];
    *highest = values[0];
    for (int i = 1; i < n; i++) {
        if (values[i] < *lowest) {
            *lowest = values[i];
        }
        if (values[i] > *highest) {
            *highest = values[i];
        }
    }
}

int main(void) {
    int x = 3;
    int y = 8;
    swap(&x, &y);
    printf("%d %d\n", x, y);
    int climbs[4] = {640, 150, 880, 300};
    int low;
    int high;
    lowest_highest(climbs, 4, &low, &high);
    printf("%d %d\n", low, high);
    return 0;
}
8 3
150 880

The caller writes &x to pass an address, and the function writes *a to reach the variable. This is why scanf takes &km: it stores what it read into the caller's variable.

Pointers and arrays

An array's name, used as a value, is a pointer to its first item. Adding 1 to a pointer moves it by one item, whatever the item's size, and a[i] means the same as *(a + i). A string can therefore be walked with a pointer until the '\0'.

#include <stdio.h>

int count_char(const char *text, char wanted) {
    int count = 0;
    for (const char *p = text; *p != '\0'; p++) {
        if (*p == wanted) {
            count++;
        }
    }
    return count;
}

int main(void) {
    int kms[3] = {12, 7, 5};
    int *p = kms;
    printf("%d %d\n", *p, *(p + 2));
    printf("%d\n", p[1] == kms[1]);
    printf("%d\n", count_char("blue ridge loop", 'e'));
    return 0;
}
12 5
1
2
  • int values[] and int *values mean the same as a parameter.
  • const char *text is a pointer through which the characters may be read but not changed; a function that only reads a string should say so.

Common mistakes

Each fragment below compiles, some with a warning, and may even seem to work on one machine. All are undefined behaviour. Week 3 shows a tool that stops the program where it happens.

Past the end of an array.

int kms[3];
kms[3] = 0;                 /* the last valid position is 2 */

No room for the end of the string.

char name[5];
strcpy(name, "Ridge");      /* needs 6 bytes */

Returning the address of a local variable. The array is gone when the function returns:

char *make_label(void) {
    char label[16] = "Loop";
    return label;
}

**Comparing strings with ==.** This compares two addresses and is false even when the letters are the same:

if (name == "Loop") {       /* wrong: strcmp(name, "Loop") == 0 */
    count++;
}

A pointer that points nowhere.

int *p;
*p = 5;                     /* p was never given an address */
