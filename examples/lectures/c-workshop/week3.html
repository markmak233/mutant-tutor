C workshop, week 3: structs, memory, a small program

Structs

In these notes, each complete program is followed by what it prints. When a program reads input, the input is shown first. A piece of code without main is a fragment: it shows one point and is not a whole program.

A struct groups values of different types under one name. typedef gives the struct type a short name, and . reaches a field.

#include <stdio.h>

typedef struct {
    char name[16];
    double km;
    int climb;
} Trail;

int main(void) {
    Trail loop = {"Loop", 12.5, 640};
    Trail trails[2] = {{"Falls", 7.0, 300}, {"Ridge", 5.5, 880}};
    loop.climb += 60;
    printf("%s: %.1f km, %d m\n", loop.name, loop.km, loop.climb);
    int total = 0;
    for (int i = 0; i < 2; i++) {
        total += trails[i].climb;
    }
    printf("%d\n", total);
    Trail copy = loop;
    copy.km = 1.0;
    printf("%.1f %.1f\n", loop.km, copy.km);
    return 0;
}
Loop: 12.5 km, 700 m
1180
12.5 1.0
  • The values in { } fill the fields in the order they are declared.
  • An array of structs keeps each record's fields together: trails[i].climb.
  • Assigning a struct copies all of it, the array inside included; the copy is independent of the original.

Structs and pointers

A struct passed to a function is copied, like any argument. Passing its address avoids the copy and lets the function change the caller's struct. p->field reaches a field through a pointer; it is short for (*p).field.

#include <stdio.h>

typedef struct {
    char name[16];
    double km;
    int climb;
} Trail;

void raise_climb(Trail *trail, int metres) {
    trail->climb += metres;
}

double steepness(const Trail *trail) {
    return trail->climb / (trail->km * 1000.0);
}

int main(void) {
    Trail ridge = {"Ridge", 5.5, 880};
    raise_climb(&ridge, 20);
    printf("%d\n", ridge.climb);
    printf("%.2f\n", steepness(&ridge));
    return 0;
}
900
0.16
  • Use . on a struct and -> on a pointer to a struct.
  • const Trail * says the function only reads the struct.
  • Had raise_climb taken a Trail, it would have changed its own copy and ridge.climb would still be 880.

malloc and free

A local array has a size fixed in the code and disappears when its function returns. malloc asks for a block of memory of a size chosen while the program runs; the block stays until free gives it back.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 4;
    int *kms = malloc(n * sizeof(int));
    if (kms == NULL) {
        return 1;
    }
    for (int i = 0; i < n; i++) {
        kms[i] = (i + 1) * 5;
    }
    printf("%d %d\n", kms[0], kms[n - 1]);
    free(kms);
    return 0;
}
5 20
  • malloc takes a number of bytes: the number of items times sizeof one item.
  • It returns NULL when no memory is left; test before using the block.
  • The block's contents are not set to 0. Write an item before reading it.
  • Each block is freed exactly once. After free, the pointer still holds the old address, and the block must not be used through it.

A growing array

When the number of values is not known in advance, start with a small block and make it larger when it is full. realloc gives a block of the new size with the old contents, possibly at another address.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int capacity = 2;
    int count = 0;
    int *values = malloc(capacity * sizeof(int));
    if (values == NULL) {
        return 1;
    }
    int value;
    while (scanf("%d", &value) == 1) {
        if (count == capacity) {
            capacity *= 2;
            int *bigger = realloc(values, capacity * sizeof(int));
            if (bigger == NULL) {
                free(values);
                return 1;
            }
            values = bigger;
        }
        values[count] = value;
        count++;
    }
    printf("%d values, capacity %d\n", count, capacity);
    if (count > 0) {
        printf("last: %d\n", values[count - 1]);
    }
    free(values);
    return 0;
}
12 7 5 9 3
5 values, capacity 8
last: 3
  • Two numbers describe the array: count, how many items are in use, and capacity, how many fit.
  • The result of realloc goes into a second pointer first. When it fails it returns NULL and the old block is still there, to be freed.
  • Doubling the capacity keeps the number of realloc calls small: 5 values needed two.

Memory errors

Mistakes with memory do not always show: the program may run and print the right answer. The four below are the common ones.

int *a = malloc(3 * sizeof(int));
a[3] = 1;                   /* past the end of the block */
free(a);
printf("%d\n", a[0]);       /* used after free */
free(a);                    /* freed twice */

int *b = malloc(10 * sizeof(int));
b = malloc(20 * sizeof(int));   /* a leak: the first block can never be freed */
free(b);

The compiler can add checks that stop the program at the faulty line:

gcc -Wall -std=c11 -g -fsanitize=address,undefined -o trips trips.c
  • AddressSanitizer reports heap-buffer-overflow for a read or write outside a block, heap-use-after-free, and attempting double-free, each with the file and line (-g adds the line numbers).
  • On Linux it also lists, when the program ends, the blocks that were never freed: detected memory leaks.
  • UndefinedBehaviorSanitizer reports, among others, a position outside a local array and a division by zero, as runtime error.

A program is correct only when it runs clean under these checks, not merely when its output looks right.

Reading lines

fgets reads one line into an array, never more than the size given, and keeps the line break. sscanf then reads values out of that line, as scanf does from the input. Reading line by line means a bad line spoils only itself.

#include <stdio.h>
#include <string.h>

int main(void) {
    char line[64];
    while (fgets(line, sizeof(line), stdin) != NULL) {
        line[strcspn(line, "\n")] = '\0';
        char walker[16];
        int km;
        if (sscanf(line, "%15s %d", walker, &km) != 2) {
            printf("skipped: [%s]\n", line);
            continue;
        }
        printf("%s walked %d km\n", walker, km);
    }
    return 0;
}

ben seven

cy 5

  • fgets returns NULL at the end of the input.
  • strcspn(line, "\n") is the position of the line break, or of the final '\0' when there is none; writing '\0' there removes the line break.
  • %15s reads one word of at most 15 characters, which with the '\0' fills the 16 bytes of walker. A plain %s would write past the array on a long word.
  • sscanf returns how many values it stored: anything but 2 here is a bad line.

A small program

The three weeks together: read walker km pairs, keep one total per walker in an array of structs, and print the walkers by total, largest first.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX_WALKERS 100

typedef struct {
    char name[16];
    int km;
} Walker;

int find(const Walker walkers[], int n, const char *name) {
    for (int i = 0; i < n; i++) {
        if (strcmp(walkers[i].name, name) == 0) {
            return i;
        }
    }
    return -1;
}

int by_km_then_name(const void *a, const void *b) {
    const Walker *x = a;
    const Walker *y = b;
    if (x->km != y->km) {
        return y->km > x->km ? 1 : -1;
    }
    return strcmp(x->name, y->name);
}

int main(void) {
    Walker walkers[MAX_WALKERS];
    int n = 0;
    char name[16];
    int km;
    while (scanf("%15s %d", name, &km) == 2) {
        int i = find(walkers, n, name);
        if (i == -1) {
            if (n == MAX_WALKERS) {
                fprintf(stderr, "too many walkers\n");
                return 1;
            }
            i = n;
            strcpy(walkers[i].name, name);
            walkers[i].km = 0;
            n++;
        }
        walkers[i].km += km;
    }
    qsort(walkers, n, sizeof(Walker), by_km_then_name);
    for (int i = 0; i < n; i++) {
        printf("%s: %d km\n", walkers[i].name, walkers[i].km);
    }
    return 0;
}

ben 7
cy 17
ana 5
ana: 17 km
cy: 17 km
ben: 7 km
  • find returns the walker's position, or -1 when the name is new: a value no position can have.
  • qsort sorts any array, given the number of items, one item's size and a function that compares two items: negative when the first goes first, positive when it goes last, 0 when they are equal.
  • Equal totals are ordered by name, so the output is the same on every run; qsort alone promises no order between equal items.

Exit status and error messages

A program reports failure in two ways: a message on standard error, written with fprintf(stderr, ...), and a non-zero exit status. Results go to standard output only, so that another program can read them without the messages.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int count;
    if (scanf("%d", &count) != 1 || count <= 0) {
        fprintf(stderr, "error: expected a positive count\n");
        return EXIT_FAILURE;
    }
    printf("%d trips\n", count);
    return EXIT_SUCCESS;
}
3
3 trips

With an input that is not a positive number, the program prints nothing on standard output:

none
error: expected a positive count
  • EXIT_SUCCESS is 0 and EXIT_FAILURE is 1 on the usual systems; both come from stdlib.h.
  • Check the input before using it, and stop early: the rest of the program can then rely on it.
  • On every path out of the program, free what was allocated and return the right status.
