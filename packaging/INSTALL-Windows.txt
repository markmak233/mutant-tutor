Tutor 0.1.0 on Windows: how to install it
=========================================

This folder holds:

    tutor-0.1.0-py3-none-any.whl   the tool
    INSTALL-Windows.txt            this file

If no editor opens this file, open it in your web browser instead (drag it onto
a browser window).

You run every command below yourself, in PowerShell; nothing installs anything
on its own. You need an internet connection: while Tutor installs, the
libraries it uses are downloaded from PyPI (pypi.org).

This version runs on Windows for x64 (Intel or AMD) computers. Windows on ARM
is not supported yet: some libraries Tutor needs have no ARM build for it.

To open PowerShell: open the Start menu, type PowerShell, press Enter.


1. Install uv (once per computer)
---------------------------------

uv is the program that installs Tutor; it goes into your user folder and needs
no administrator rights. In PowerShell, run:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

uv's own instructions are at https://docs.astral.sh/uv/getting-started/installation/
If uv is already installed, skip this step.

Close PowerShell, open a new one, and check that it answers:

    uv --version


2. Install Tutor
----------------

PowerShell must be in this folder, the one holding the .whl file. The easiest
way: open this folder in File Explorer, click the address bar at the top, type
powershell, and press Enter. (Explorer's "Extract All" may put the files one
folder deeper than you expect; use the folder that holds the .whl file.)

Then run this, with the quotes:

    uv tool install --python 3.11 "tutor-0.1.0-py3-none-any.whl[gen,gui,doctor]"

If this computer has no Python 3.11, uv first downloads its own copy into your
user folder; that needs no administrator rights. To use only a Python you
installed yourself, add --no-python-downloads to the command.

Then, once, so that the `tutor` command is found:

    uv tool update-shell

and close PowerShell and open a new one.


3. Start it
-----------

    tutor gui

starts Tutor and opens it in your browser. Keep that PowerShell window open
while you use it; Ctrl+C there stops it.

To start it with a double-click from now on, run once:

    tutor shortcut

It puts a "Tutor" shortcut on your desktop (also when OneDrive keeps your
desktop). Opening it starts Tutor in a small window that stays minimised in
the taskbar: closing that window stops Tutor.

Your courses are kept in this folder:

    $env:LOCALAPPDATA\Tutor\courses     (as PowerShell writes it)
    %LOCALAPPDATA%\Tutor\courses        (in File Explorer's address bar)

To keep them somewhere else, give the folder each time:
tutor gui --root FOLDER (and tutor shortcut --root FOLDER for the shortcut).

To check what this computer has and lacks:

    tutor doctor


4. Docker (only for courses that run their tests in a container)
----------------------------------------------------------------

A course can run its tests on this computer or in a container. The container
needs Docker Desktop, which you install yourself from
https://docs.docker.com/desktop/setup/install/windows-install/
(read its licence terms there). It can be installed for all users, which needs
administrator rights, or for your user only. On its first start it may ask to
turn on WSL 2 ("Virtual Machine Platform") and restart the computer, which
needs administrator rights.

After installing it, close PowerShell and open a new one: only a new one finds
the `docker` command, and a Tutor started from an old one says Docker is not
installed. Once it is installed, Tutor starts it when needed.

Docker Desktop needs hardware virtualisation, which most virtual machines and
Windows Sandbox do not pass on: there, choose "on this machine" for a course's
tests instead.

Courses in C always need Docker, since their tests run only in a container. On
Windows, a C test may now and then stop after 5 seconds with "did not finish"
even though the program is right (a known issue with Docker Desktop's settings,
to be fixed): run the tests again.


5. Update to a new version
--------------------------

Open PowerShell in the new version's folder (as in step 2) and run the same
command with --force, with the new file's name:

    uv tool install --force --python 3.11 "tutor-NEW-VERSION-py3-none-any.whl[gen,gui,doctor]"

Your courses are not touched.


6. Uninstall
------------

    uv tool uninstall tutor

Your courses folder (step 3) and the desktop shortcut stay; delete them
yourself if you no longer want them. To remove uv too, see the uninstall part
of uv's instructions (step 1's link).


7. If something goes wrong
--------------------------

- "tutor : The term 'tutor' is not recognized": run uv tool update-shell,
  then open a new PowerShell.
- "certificate not valid yet" or "certificate expired": this computer's clock
  is wrong (common in a virtual machine that was off for a long time). In
  Settings > Time & language > Date & time, turn on "Set time automatically"
  and press "Sync now", then try again.
- The browser did not open: copy the "Open http://127.0.0.1:..." line that
  tutor gui printed into your browser.
- "Docker is not running": start Docker Desktop, wait until it says it is
  running, then press "Check again" on the course's Environment page.
