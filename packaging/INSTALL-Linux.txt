Tutor 0.1.0 on Linux: how to install it
=======================================

This folder holds:

    tutor-0.1.0-py3-none-any.whl   the tool
    INSTALL-Linux.txt              this file

You run every command below yourself, in a terminal; nothing installs anything on
its own. You need an internet connection: while Tutor installs, the libraries it
uses are downloaded from PyPI (pypi.org).

To open a terminal on Ubuntu: press Ctrl+Alt+T, or open "Terminal" from the
applications list.


1. Install uv (once per computer)
---------------------------------

uv is the program that installs Tutor; it goes into your home folder and needs
no administrator rights. Run:

    curl -LsSf https://astral.sh/uv/install.sh | sh

If that says "curl: command not found" (a fresh Ubuntu may not have curl), run
this instead:

    wget -qO- https://astral.sh/uv/install.sh | sh

uv's own instructions are at https://docs.astral.sh/uv/getting-started/installation/
If uv is already installed, skip this step.

Close the terminal, open a new one, and check that it answers:

    uv --version


2. Install Tutor
----------------

Go to this folder, the one holding the .whl file. For example, if you unpacked
it in Downloads:

    cd ~/Downloads/tutor-0.1.0

Then run this, with the quotes:

    uv tool install --python 3.11 "tutor-0.1.0-py3-none-any.whl[gen,gui,doctor]"

If this computer has no Python 3.11, uv first downloads its own copy into your
home folder; that needs no administrator rights. To use only a Python you
installed yourself, add --no-python-downloads to the command.

Then, once, so that the `tutor` command is found:

    uv tool update-shell

and close the terminal and open a new one.


3. Start it
-----------

    tutor gui

starts Tutor and opens it in your browser. Keep that terminal open while you
use it; Ctrl+C there stops it.

To start it with a double-click from now on, run once:

    tutor shortcut

It puts a "Tutor" launcher (tutor.desktop) in ~/Desktop. On Ubuntu's desktop,
right-click it and choose "Allow Launching" before the first double-click. If
you have no ~/Desktop folder (or it has another name in your language), say
where to put it:

    tutor shortcut --directory FOLDER

Your courses are kept in this folder:

    ~/.local/share/tutor/courses

To keep them somewhere else, give the folder each time:
tutor gui --root FOLDER (and tutor shortcut --root FOLDER for the launcher).

To check what this computer has and lacks:

    tutor doctor


4. Docker (only for courses that run their tests in a container)
----------------------------------------------------------------

A course can run its tests on this computer or in a container. The container
needs Docker, which you install yourself (it needs administrator rights):

- Docker Engine: https://docs.docker.com/engine/install/
  Also do its "post-installation steps" page, so that your user can run docker
  without sudo; Tutor runs docker as you. After adding yourself to the docker
  group, log out and log in again (or restart): until then, docker answers
  "permission denied". Docker Engine usually starts when the computer starts;
  if it does not, start it yourself: Tutor does not start it.
- Docker Desktop for Linux: https://docs.docker.com/desktop/setup/install/linux/
  Tutor starts it when needed. It needs hardware virtualisation (KVM), which
  most virtual machines do not pass on: inside a virtual machine, use Docker
  Engine instead.

Without Docker, choose "on this machine" for a course's tests.


5. Update to a new version
--------------------------

Go to the new version's folder and run the same command with --force, with the
new file's name:

    uv tool install --force --python 3.11 "tutor-NEW-VERSION-py3-none-any.whl[gen,gui,doctor]"

Your courses are not touched.


6. Uninstall
------------

    uv tool uninstall tutor

Your courses folder (step 3) and the desktop launcher stay; delete them
yourself if you no longer want them. To remove uv too, see the uninstall part of
uv's instructions (step 1's link).


7. If something goes wrong
--------------------------

- "tutor: command not found": run uv tool update-shell, then open a new
  terminal.
- "certificate not valid yet" or "certificate expired": this computer's clock
  is wrong (common in a virtual machine that was off for a long time). Turn on
  automatic date and time in the system settings, then try again.
- The browser did not open: copy the "Open http://127.0.0.1:..." line that
  tutor gui printed into your browser.
- "Docker is not running": start Docker (see step 4), then press "Check again"
  on the course's Environment page.
- "permission denied" from docker: your user is not in the docker group yet,
  or you have not logged in again since; see step 4.
