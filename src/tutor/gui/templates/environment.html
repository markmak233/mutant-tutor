Installs this tool and the pip packages in [requires] into the course's .venv; what is there already is left as it is.
Where
Only inside {{ course.workspace.root }}/.venv. Nothing outside the course folder changes: no PATH, no shell profile.
Admin rights
None (no sudo).
Downloads from
PyPI, through pip.
